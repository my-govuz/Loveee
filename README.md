# Loveee

Премиальный романтический сайт-поздравление для Парижон: интерактивная mobile-first история любви Самиржона и Парижон к годовщине — 7 месяцев вместе.

## Как запустить

Откройте `index.html` в браузере или запустите локальный сервер:

```bash
python3 -m http.server 4173
```

Затем перейдите на `http://127.0.0.1:4173/`.

## Как добавить свои фото и видео

1. Положите фотографии в папку `images/`.
2. Положите видео или кружочки в папку `videos/`.
3. Добавьте элементы в `media-manifest.js`:

```js
{ type: 'image', src: 'images/photo-1.jpg', title: 'Наш день', caption: 'Любимое воспоминание' },
{ type: 'video', src: 'videos/moment.mp4', title: 'Авиация', caption: 'Та самая встреча' }
```

## Настройка даты

Дата начала отношений находится в переменной `RELATIONSHIP_START` в `script.js`.
